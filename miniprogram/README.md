# 墨映 · 四色墨水屏微信小程序

工程目录：本仓库的 `miniprogram/`。直接在微信开发者工具中打开此目录，无需安装 npm 依赖或配置服务器。

## 已有功能

- 未连接时选图和编辑，支持相册/拍照。
- 768×552 四色预览，黑白黄红 2bpp，预览像素与发送帧一致。
- 25%～300% 缩放、适应屏幕、90°旋转、照片抖动和颜色反转。
- 红、黑、黄独立深浅滑杆（0%～200%，100% 默认），松手更新预览，可一键恢复默认；调节同步用于发送画面。
- 外观仅有浅色、深色、跟随系统，保存本地选择；系统外观变化时自动更新。
- 扫描、选择、连接 `EPD-Calendar` 设备，进度显示、全白清屏。
- EP v1 命令应答、CRC16/CRC32、顺序分包、通知拆包、忙状态重试与断线续传。
- 对本项目固件的可选状态特征进行轮询，确认物理刷新完成；上游没有该特征时提示“已保存，设备已安排刷新”。

## 手机测试

1. 在开发者工具点击“编译”，确认墨映页面显示正常。
2. 点击“预览”，用手机微信扫码。模拟器可以测试选图/缩放/主题；真实蓝牙请在手机测试。
3. 打开手机系统蓝牙，并按微信提示允许蓝牙访问。先断开安卓 App 与设备的连接，设备只允许一个连接。
4. 可先选择图片并调整，再向下滚到“连接墨水屏” → 扫描附近设备 → 选择设备 → 连接。
5. 点击“发送到墨水屏”，保持小程序在前台、手机靠近设备，等待最终完成提示。
6. 清屏会以全白图片替换当前照片槽，因此有确认提示。
7. 传输中断后，在同一小程序会话中重连，发送相同帧可从设备返回的偏移续传。重新选图/调整画面或退出小程序后需要从头发送。

公开源码使用 `touristappid` 占位；真机预览、上传或发布前，请在开发者工具中填写自己的小程序 AppID。若真机预览或发布要求补充隐私指引，请在微信公众平台按实际使用的图片选择、相机与蓝牙能力填写并完成平台要求。没有登录、云服务、图片上传或分析埋点；照片只在手机本地处理，再通过 BLE 发送给设备。

## 真机调试与体验版

如果二维码真机调试面板显示 `sessionerror / Client network socket disconnected before secure TLS connection was established`，这是开发者工具连接微信调试服务失败，与 BLE 数据帧无关。可检查开发者工具的代理设置，并按需启用局域网调试；这些属于本机设置，不包含在公开源码中。使用局域网模式时，手机和电脑须处于同一可互访 Wi-Fi，重新启动真机调试后扫码验证。请不要通过关闭证书校验来处理此错误。

自己长期测试可使用体验版：开发者工具“上传” → 登录微信公众平台的小程序账号 → 版本管理 → 开发版本 → 设为体验版 → 成员管理添加体验成员 → 微信扫码打开。必须使用自己的小程序 AppID，并具有该项目开发者权限。体验版不需要每次连接电脑，但上传不等于正式发布，也不会自动出现在公众搜索结果中。公开使用需要按平台要求提交审核并发布。

## 设备协议

私有服务 `7b4d0001-6a6c-4c61-9f20-65706463616c`；Control/Notify/Image 分别为 0002/0003/0004，可选 Status 为 0005。
帧格式 `EP + version + command + sequence(u16) + length(u16) + payload + CRC16`，整数小端。
每张图 105984 字节，四像素一字节，高位像素在前，0黑/1白/2黄/3红。

该协议与当前安卓工程和 ESP32 固件一致，不能与最早的 `7e400001...` BLE 固件混用。
Android 尝试协商 MTU 247，并读取实际 MTU；其它平台读取系统协商值，不可用时退回 MTU 23。
小 MTU 兼容模式速度较慢。普通 BLE 请求和通知等待有超时，重试不会重复提交副作用。

## 文件与验证

- `pages/index/`：页面、Canvas 2D 合成和交互。
- `utils/image.js`：缩放计算、四色量化与蛇形 Floyd–Steinberg 抖动。
- `utils/protocol.js`：协议编解码、CRC、设备信息与状态解析。
- `utils/ble.js`：原生微信 BLE API、串行传输与会话管理。
- `tests/checks.test.js`：Node 原生测试；`node --test tests/checks.test.js`。
- `tests/four-colour.png`：离线测试图，不打包到小程序。

已用本机微信 WXML/WXSS 编译器编译，并在开发者工具模拟器检查页面、主题切换和离线选图。
自动测试覆盖标准 CRC 向量、损坏/拆分/粘连通知、最小和大 MTU 整帧还原、缩放与打包、模拟设备应答先于写完成、忙状态重试、断线续传、清屏和提交校验。
尚未完成手机微信与实体墨水屏的实际 BLE 联调。
